\begin{enumerate}[label=(\alph*)]

\end{enumerate}
\item Of the following problems concerning a given undirected graph G, which is currently known to be solvable in polynomial time?
\begin{enumerate}[label=(\alph*)]
    \item Finding a longest simple cycle in G
    \item Finding a shortest cycle in G
    \item Finding ALL spanning trees of G
    \item Finding a largest clique in G
\end{enumerate}
\item Of the following sorting algorithms, which has a running time that is LEAST dependent on the initial ordering of the input?

    \item Quicksort
    \item Merge sort
    \item Selection sort
\end{enumerate}
\end{enumerate}
