\section*{Multiple Choice Questions (Single correct)}
\textit{Instructions: Select the correct option with a short explanation.}
\begin{enumerate}[label=Q\arabic*.]
\item What is one of the key limitations of RNN?
\begin{enumerate}[label=(\Alph*)]
    \item They cannot process sequences
    \item They are too computationally cheap
    \item They cannot use embeddings
    \item They struggle with long-range dependencies
\end{enumerate}
\item Which model type is generally best for text classification tasks (e.g., sentiment analysis)?
\begin{enumerate}[label=(\Alph*)]
    \item Encoder-only
    \item Decoder-only
    \item Encoder-decoder
    \item None of the above
\end{enumerate}
\item What does self-attention allow a model to do?
\begin{enumerate}[label=(\Alph*)]
    \item Process only one token at a time
    \item Attend to other tokens within the same sequence
    \item Ignore context entirely
    \item Only use previous tokens
\end{enumerate}
\item What is a key characteristic of transformers compared to RNNs?
\begin{enumerate}[label=(\Alph*)]
    \item They process tokens strictly sequentially
    \item They rely on recurrence
    \item They use self-attention instead of recurrence
    \item They cannot handle sequences
\end{enumerate}
\item Which model would work best for a task like summarization?
\begin{enumerate}[label=(\Alph*)]
    \item Encoder-only
    \item Decoder-only
    \item Encoder-decoder
    \item None
\end{enumerate}
\item What is a key advantage of Rotary Positional Embeddings?
\begin{enumerate}[label=(\Alph*)]
    \item They require no training data
    \item They eliminate attention
    \item They only work for short sequences
    \item They preserve relative positions and generalize well
\end{enumerate}
\item What type of transformer is BERT?
\begin{enumerate}[label=(\Alph*)]
    \item Encoder-only
    \item Decoder-only
    \item Encoder-decoder
    \item Recurrent transformers
\end{enumerate}
\item What is the main objective used to pre-train BERT?
\begin{enumerate}[label=(\Alph*)]
    \item Next-word prediction
    \item Image classification
    \item Masked language modeling
    \item Reinforcement learning
\end{enumerate}
\item Which type of positional encoding uses sine and cosine functions?
\begin{enumerate}[label=(\Alph*)]
    \item Learned positional encoding
    \item Relative positional encoding
    \item Rotary positional encoding
    \item Sinusoidal positional encoding
\end{enumerate}
\item What is multi-head attention used for?
\begin{enumerate}[label=(\Alph*)]
    \item Reducing model parameters
    \item Capturing diverse relationships in data
    \item Eliminating positional encoding
    \item Replacing embeddings
\end{enumerate}
\end{enumerate}
