16. Sample answer:

Write a function to find numbers greater than `n` from a list of numbers using a lambda function.
   
   

def find_greater_than(numbers, n):
       return list(filter(lambda x: x > n, numbers))

   # Example usage:
   numbers_list = [1, 5, 10, 15, 20]
   n = 10
   print(find_greater_than(numbers_list, n))  # Output: [15, 20]
