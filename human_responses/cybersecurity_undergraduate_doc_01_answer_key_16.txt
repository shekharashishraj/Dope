16. Sample answer:

def count_divisible(numbers, m, n):
   return len(list(filter(lambda x: x % m == 0 or x % n == 0, numbers)))

# Example usage
numbers = [10, 15, 20, 25, 30]
m = 5
n = 3
print(count_divisible(numbers, m, n))  # Output: 5
