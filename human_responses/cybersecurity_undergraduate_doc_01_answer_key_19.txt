16. Sample answer:

def find_divisible(numbers, m, n):
       return list(filter(lambda x: x % m == 0 or x % n == 0, numbers))

   # Example usage:
   numbers = [10, 20, 33, 40, 50]
   m, n = 5, 10
   result = find_divisible(numbers, m, n)
   print(result)  # Output: [10, 20, 40, 50]
