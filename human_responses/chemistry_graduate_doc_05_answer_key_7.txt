11. Sample answer:

The relationship between half-life ( t 1 / 2 ) and the rate constant ( k ) for a first-order reaction is given by the formula: t 1 / 2 = 0.693 k Given that the half-life is 69 minutes, we can calculate the rate constant as follows: k = 0.693 69 \, \text { minutes } = 0.010 \, \text { min } ^ { -1 } For a first-order reaction, the half-life is constant and does not depend on the initial concentration of the reactant. 

This means that with each passing half-life, half of the remaining reactant is consumed.


12. Sample answer:

According to Charles's Law, the volume ( V ) of a gas is directly proportional to its temperature ( T ) when pressure is constant. 

This can be expressed by: \frac { V _ { 1 } } { T _ { 1 } } = \frac { V _ { 2 } } { T _ { 2 } } Given an initial volume ( V 1 ) of 100 ml at 20°C (293 K), and a final temperature ( T 2 ) of 10°C (283 K), we can find the final volume ( V 2 ): V 2 = V 1 \times \frac { T 2 } { T 1 } = 100 \, \text { ml } \times \frac { 283 } { 293 } \approx 96.6 \, \text { ml } This demonstrates that as the temperature decreases, the volume also decreases, maintaining constant pressure. 

The law highlights the direct relationship between temperature and volume.
