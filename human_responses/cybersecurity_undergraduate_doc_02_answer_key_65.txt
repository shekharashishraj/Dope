11. Sample answer:

Write a function to check whether the given number is even or not.


def is_even(number):

12. Sample answer:

Write a function to sort a tuple by its string element.


def sort_tuple_by_string(input_tuple):
    return tuple(sorted(input_tuple, key=lambda x: str(x)))
