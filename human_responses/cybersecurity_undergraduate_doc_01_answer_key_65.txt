16. Sample answer:

def find_divisibles(numbers, m, n):
       return list(filter(lambda x: x % m == 0 or x % n == 0, numbers))

   # Example usage
   numbers = [10, 15, 20, 25, 30, 35]
   m = 5
   n = 3
   print(find_divisibles(numbers, m, n))
   

   This function uses a lambda function with the `filter` to select numbers divisible by either \( m \) or \( n \).
