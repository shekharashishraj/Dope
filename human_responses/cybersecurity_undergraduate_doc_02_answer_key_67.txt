11. Sample answer:

Function to check if a number is palindrome:

def is_palindrome(number):
    original = str(number)
    reversed_num = original[::-1]
    return original == reversed_num


12. Sample answer:

Function to sort a tuple by its date element:

from datetime import datetime

def sort_by_date(tuples_list):
    return sorted(tuples_list, key=lambda x: datetime.strptime(x[1], '%Y-%m-%d'))
