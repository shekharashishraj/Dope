16. Sample answer:

def filter_divisible(numbers, m, n):
    return list(filter(lambda x: x % m == 0 or x % n == 0, numbers))

numbers = [10, 20, 25, 30, 35, 40]
m = 5
n = 10
filtered_numbers = filter_divisible(numbers, m, n)
print(filtered_numbers)

This function filters numbers from a given list that are divisible by either `m` or `n` using a lambda function.
