\section*{Multiple Choice (10 marks)}
\begin{enumerate}[label=\arabic*.]
\item If a, b, and c are integers, which of the following conditions is sufficient to guarantee
that the expression a \textless{} c || a \textless{} b \&\& !(a == c) evaluates to true?
\begin{enumerate}[label=(\alph*)]
    \item a \textless{} c
    \item a \textless{} b
    \item a \textgreater{} b
    \item a == b
\end{enumerate}
\item In Python 3, what is ['a', 'Chemistry', 0, 1][-3]?
\begin{enumerate}[label=(\alph*)]
    \item a
    \item Chemistry
    \item 0
    \item 1
\end{enumerate}
\item What is the value of this python expression: 4 + 3 \% 2?
\begin{enumerate}[label=(\alph*)]
    \item 1
    \item 6
    \item 4
    \item 5
\end{enumerate}
\item In Python 3, let r = lambda q: q * 2. What is r(3)?
\begin{enumerate}[label=(\alph*)]
    \item 2
    \item 6
    \item 3
    \item 1
\end{enumerate}
\item Which of the following spreadsheet functions would be most useful for detecting improbably
high or low values that have become part of a data set as a result of data entry errors?
\begin{enumerate}[label=(\alph*)]
    \item A function that averages numeric values in a column or row
    \item A function that counts the values in a column or row
    \item A function that rounds a numeric value
    \item A function that sorts values in a column or row
\end{enumerate}
\end{enumerate}
