\section*{Multiple Choice (10 marks)}
\begin{enumerate}[label=\arabic*.]
\item What is the minimum number of people needed in a room to guarantee that there are 4 mutual
friends or 4 mutual strangers?
\begin{enumerate}[label=(\alph*)]
    \item 18
    \item 14
    \item 10
    \item 25
    \item 30
\end{enumerate}
\item Suppose f is analytic on the closed unit disk, f(0) = 0, and |f(z)| $\leq$ |e\^{}z| whenever
|z| = 1. How big can f((1 + i)/2) be? Return a numerical number.
\begin{enumerate}[label=(\alph*)]
    \item 2.3456
    \item 2.2360
    \item 3.0000
    \item 2.9876
    \item 1.9221
\end{enumerate}
\item Evaluate $\int_c z^2 / (z - 5) dz$, where c is the circle that $|z| = 2$.
\begin{enumerate}[label=(\alph*)]
    \item $2\pi i$
    \item 0
    \item $-2\pi i$
    \item 1
    \item $4\pi i$
\end{enumerate}
\item A coach rounded the number of runners at a track meet to the nearest 10. The rounded
number of runners is 400. Which number could be the actual number of runners at the track
meet?
\begin{enumerate}[label=(\alph*)]
    \item 411
    \item 382
    \item 420
    \item 447
    \item 375
\end{enumerate}
\item Statement 1 | 4x - 2 is irreducible over Z. Statement 2 | 4x - 2 is irreducible over Q.
\begin{enumerate}[label=(\alph*)]
    \item True, Not enough information
    \item Not enough information, False
    \item False, False
    \item Not enough information, Not enough information
    \item Not enough information, True
\end{enumerate}
\end{enumerate}

\section*{True / False (10 marks)}
\textit{Answer True or False}
\begin{enumerate}[label=\arabic*.]
\setcounter{enumi}{5}
\item True or False: For a 2 * 2 matrix A to satisfy AM = MD for some nonzero matrix M, the eigenvalues of A must be [2, 3].
\item True or False: The greatest common factor of 252 and 96 is 12.
\item True or False: The limit of the sequence a\_n as n approaches infinity is 0.5, given the conditions 0 \textless{} a\_n \textless{} 1 and (1-a\_n)a\_\{n+1\} \textgreater{} 1/4.
\item True or False: The correct answer to 'x=0.3168. what is the value of $x*\prod_{n=1}^\infty(1-\frac{x^2}{n^2 \pi^2})/sin(x)$?' is '3.14'.
\item True or False: The set of nonzero integers under multiplication does not satisfy the group axioms, as it lacks an identity element.
\end{enumerate}
