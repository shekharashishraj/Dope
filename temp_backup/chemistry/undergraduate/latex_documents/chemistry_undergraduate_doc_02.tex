\section*{True / False (20 marks)}
\textit{Answer True or False and justify briefly.}
\begin{enumerate}[label=\arabic*.]
\item True or False: The correct answer to 'A buffer is made from equal concentrations of a weak acid and its conjugate base. Doubling the volume of the buffer solution by adding...' is 'It significantly decreases the pH.'.
\item True or False: The correct answer to 'Which of the following is lower for argon than for neon?' is 'First ionization energy'.
\item True or False: The correct answer to 'The T2 of an NMR line is 15 ms. Ignoring other sources of linebroadening, calculate its linewidth.' is '21.2 Hz'.
\item True or False: The correct answer to 'The anhydride of Ba(OH)2 is' is 'BaO'.
\item True or False: The correct answer to 'Which of the following compounds has a 1H resonance approximately 1.55 kHz away from TMS on a spectrometer with a 12.0 T magnet?' is 'CH3F'.
\item True or False: The correct answer to 'Cobalt-60 is used in the radiation therapy of cancer and can be produced by bombardment of cobalt-59 with which of the following?' is 'Neutrons'.
\item True or False: The correct answer to 'The strongest base in liquid ammonia is' is 'NH4+'.
\item True or False: The correct answer to 'What is the maximum number of phases that can be at equilibrium with each other in a three component mixture?' is '3'.
\item True or False: The correct answer to 'Of the following ions, which has the smallest radius?' is 'Sc3+'.
\item True or False: The correct answer to '23Na has an NMR frequency of 198.52 MHz in a 750 MHz NMR spectrometer. What is its magnetogyric ratio?' is '101.1 x 10\^{}7 T-1 s-1'.
\end{enumerate}
