\section*{Multiple Choice (10 marks)}
\begin{enumerate}[label=\arabic*.]
\item A starvation-free job-scheduling policy guarantees that no job waits indefinitely for
service. Which of the following job-scheduling policies is starvation-free?
\begin{enumerate}[label=(\alph*)]
    \item Youngest job first
    \item Least frequently used
    \item Round-robin
    \item Most recently used
    \item Longest job first
\end{enumerate}
\item Let l = [1,2,3,4]. What is min(l) in Python3?
\begin{enumerate}[label=(\alph*)]
    \item '1'
    \item 0
    \item -1
    \item 3
    \item [1,2,3,4]
\end{enumerate}
\item Which is the largest asymptotically?
\begin{enumerate}[label=(\alph*)]
    \item O(n\^{}2)
    \item O(n\^{}3)
    \item O(sqrt(n))
    \item O(2\^{}n)
    \item O(log n)
\end{enumerate}
\item If the peak voltage value of a signal is 20 times the peak voltage value of the noise,
what is the SNR? What is the $\mathrm{SNR}_{\mathrm{dB}}$ (in 3 sig.fig.)?
\begin{enumerate}[label=(\alph*)]
    \item 15.0
    \item 13.0
    \item 30.0
    \item 34.0
    \item 26.0
\end{enumerate}
\item Which of the following statements about a remote procedure call is true?
\begin{enumerate}[label=(\alph*)]
    \item It is used to call procedures with addresses that are farther than 2\^{}16 bytes away.
    \item It cannot return a value.
    \item It cannot pass parameters by reference.
    \item It cannot call procedures implemented in a different language.
\end{enumerate}
\end{enumerate}
