\section*{Multiple Choice (10 marks)}
\begin{enumerate}[label=\arabic*.]
\item In Python 3, what is the output of ['Hi!'] * 4?
\begin{enumerate}[label=(\alph*)]
    \item ['Hi!', 'Hi!', 'Hi!', 'Hi!']
    \item ['Hi!'] * 4
    \item Error
    \item None of the above.
\end{enumerate}
\item A large Java program was tested extensively, and no errors were found. What can be
concluded?
\begin{enumerate}[label=(\alph*)]
    \item All of the preconditions in the program are correct.
    \item All of the postconditions in the program are correct.
    \item The program may have bugs.
    \item Every method in the program may safely be used in other programs.
\end{enumerate}
\item Let l = [1,2,2,3,4]. In Python3, what is a possible output of set(l)?
\begin{enumerate}[label=(\alph*)]
    \item \{1\}
    \item \{1,2,2,3,4\}
    \item \{1,2,3,4\}
    \item \{4,3,2,2,1\}
\end{enumerate}
\item In Python 3, what is the output of print list[1:3] if list = [ 'abcd', 786 , 2.23, 'john',
70.2 ]?
\begin{enumerate}[label=(\alph*)]
    \item [ 'abcd', 786 , 2.23, 'john', 70.2 ]
    \item abcd
    \item [786, 2.23]
    \item None of the above.
\end{enumerate}
\item What is the output of the statement "a" + "ab" in Python 3?
\begin{enumerate}[label=(\alph*)]
    \item Error
    \item aab
    \item ab
    \item a ab
\end{enumerate}
\end{enumerate}
