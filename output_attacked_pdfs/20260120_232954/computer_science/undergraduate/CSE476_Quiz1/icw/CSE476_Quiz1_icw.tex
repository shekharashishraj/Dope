\section*{Multiple Choice Questions (Single correct)}
\textit{Instructions: Select the correct option with a short explanation.}
\begin{enumerate}[label=Q\arabic*.]
\item In the BIO tagging scheme for NER, what does the ``B-'' prefix indicate?
\begin{enumerate}[label=(\Alph*)]
    \item Between two tokens
    \item Beginning of an entity
    \item Inside an entity
    \item Outside any entity
\end{enumerate}
\item Which statement best describes a (plain) Markov chain in sequence tagging?
\begin{enumerate}[label=(\Alph*)]
    \item It uses only words (observations) and ignores labels
    \item It models transitions between labels but does not consider the words
    \item It models emissions P(word | label)
    \item It is identical to an HMM
\end{enumerate}
\item In a Hidden Markov Model (HMM) for NER, an emission probability is:
\begin{enumerate}[label=(\Alph*)]
    \item P(label | previous label)
    \item P(word | label)
    \item P(label | word)
    \item P(word | previous word)
\end{enumerate}
\item In an n-gram language model, a bigram LM predicts the next word using:
\begin{enumerate}[label=(\Alph*)]
    \item No previous words
    \item The previous 1 word
    \item The previous 2 words
    \item The entire sentence history
\end{enumerate}
\item Which statement about perplexity is correct?
\begin{enumerate}[label=(\Alph*)]
    \item It's the raw probability of a sentence
    \item It's the inverse probability of a test text, normalized by length
    \item It's the fraction of correctly labeled tokens
    \item It's the number of unique words in the corpus
\end{enumerate}
\item Which of the following best describes the main goal of tokenization in NLP?
\begin{enumerate}[label=(\Alph*)]
    \item To label each token with a grammatical category
    \item To convert text into a sequence of symbols suitable for modeling
    \item To reduce vocabulary size to zero
    \item To assign probabilities to sentences
\end{enumerate}
\item Why is splitting text by spaces (text.split(" ")) considered an insufficient tokenizer?
\begin{enumerate}[label=(\Alph*)]
    \item It produces too many tokens
    \item It does not work well for languages without explicit word boundaries
    \item It cannot tokenize English at all
    \item It ignores punctuation entirely
\end{enumerate}
\item Which of the following is NOT listed as a common sequence tagging task?
\begin{enumerate}[label=(\Alph*)]
    \item Part-of-speech tagging
    \item Named Entity Recognition
    \item Dependency parsing
    \item Sentiment analysis
\end{enumerate}
\item What is a common limitation of BIO tagging for Named Entity Recognition?
\begin{enumerate}[label=(\Alph*)]
    \item It cannot represent overlapping or nested entities
    \item It requires too many labels
    \item It does not support multiple entity types
    \item It ignores entity boundaries
\end{enumerate}
\item When choosing between character-level tokenization and sentence-level tokenization, which trade-off must be considered?
\begin{enumerate}[label=(\Alph*)]
    \item Speed vs accuracy
    \item Tokenized sequence length vs vocabulary size
    \item Precision vs recall
    \item Memory vs computation
\end{enumerate}
\end{enumerate}
