    \item Between two tokens
    \item Beginning of an entity
    \item Inside an entity
    \item Outside any entity
\end{enumerate}
\item Which statement best describes a (plain) Markov chain in sequence tagging?
\begin{enumerate}[label=(\Alph*)]
    \item It uses only words (observations) and ignores labels
    \item It models transitions between labels but does not consider the words
    \item It models emissions P(word | label)

\end{enumerate}
\item In a Hidden Markov Model (HMM) for NER, an emission probability is:
\begin{enumerate}[label=(\Alph*)]
    \item P(label | previous label)
    \item P(word | label)

    \item P(word | previous word)
\end{enumerate}
\item In an n-gram language model, a bigram LM predicts the next word using:
\begin{enumerate}[label=(\Alph*)]
    \item No previous words
    \item The previous 1 word
    \item The previous 2 words
    \item The entire sentence history
\end{enumerate}
\item Which statement about perplexity is correct?
\begin{enumerate}[label=(\Alph*)]

    \item It's the inverse probability of a test text, normalized by length
    \item It's the fraction of correctly labeled tokens
    \item It's the number of unique words in the corpus
\end{enumerate}
\end{enumerate}
